# PRAXAK — praxak.com

Portfolio site for PRAXAK, a high-retention short-form video studio.

Live: https://akashaychandranu-cell.github.io/AK/

Static site, no build step on the host. `index.html` + `media/` (cover loops and posters).
To swap a work clip, replace `media/wN.mp4` and `media/wN.jpg` with the same names.
